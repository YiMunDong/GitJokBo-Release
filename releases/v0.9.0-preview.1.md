# GitJokBo 0.9.0 Preview 1

The first public GitJokBo preview is available for Windows x64. This is a pre-release for testing and feedback, built with the ReleasePreview configuration.

## Download

**[Download GitJokBo-0.9.0-preview.1-win-x64.zip](https://github.com/YiMunDong/GitJokBo-Release/releases/download/v0.9.0-preview.1/GitJokBo-0.9.0-preview.1-win-x64.zip)** — 5.38 MiB (5,643,995 bytes).

Extract the ZIP, keep `Languages` beside `GitJokBo.exe`, and run the executable. The archive contains only the app and its language folder. GitHub's **Source code** downloads contain the distribution repository, not the application.

Requirements: Windows 10 version 1903 or later, x64 (Windows 11 recommended); [Git for Windows](https://gitforwindows.org/) 2.35 or later; and the [Microsoft Visual C++ x64 Redistributable](https://aka.ms/vc14/vc_redist.x64.exe). Install Git and the runtime separately.

The executable is unsigned. Keep a backup of important work when evaluating this preview. Settings and local data use the standard GitJokBo application-data folders; see the [README](https://github.com/YiMunDong/GitJokBo-Release#get-started).

## What to try

- Follow branches and merges in the animated lineage view, then inspect commits and diffs.
- Stage files or hunks, make commits, and arrange mixed changes into a sequence with the visual commit composer.
- Work with branches, tags, remotes, stashes, and conflict resolution.
- Investigate file history and line blame, or use revert, cherry-pick, and reset when appropriate.
- Explore historical code with Galaxy Time Machine and watch recent history in Kim Cine.
- Choose Cyber Joseon, Soft Glass, Jelly Pop, or Hyper80s; use English, Korean, Japanese, Simplified Chinese, or the optional traditional-style Korean pack.

The preview identifies itself as `0.9.0-preview.1` and includes a **Visit release page** link in the main and About windows. The current screenshots were captured before this preview banner was added.

## Validation and feedback

The ReleasePreview build, language packs, ZIP contents, embedded license/notice hashes, and launch of the extracted package were checked on the development PC. This is not a declaration that final 1.0 validation is complete; clean-PC and broader manual validation remain outstanding.

The license, app notices, and third-party notices are embedded in the executable and available from **About**. The [license agreement](https://github.com/YiMunDong/GitJokBo-Release/blob/main/License.md) is also available online.

[Report a problem or share feedback](https://github.com/YiMunDong/GitJokBo-Release/issues). Include the app, Windows, and Git versions and the steps to reproduce the problem. Replies may take some time; thank you for your patience and understanding.
