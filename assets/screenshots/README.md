# Screenshot notes

These images are actual GitJokBo application-window captures, taken on October 27, 2026, with the display language set to English.

They show a development build before the first public release. They are not interface mockups or evidence that a particular release is available.

## Demonstration project

The fictional **Dalbit** notes project was created for these screenshots. Its local Git repository contains 14 commits, five local branches, two tags, and four pending file changes. The commits and merges are real Git objects, but the project, author identity, code examples, and dates are demonstration material. No private project source or credentials are shown.

The three commits in the composer image are a plan, not completed commits. The search implementation and its test share the first slot; the theme adjustment and guide each have their own slot.

## Capture method

- Native application-window capture at 1680 × 1000 pixels, saved as PNG.
- Separate application settings and a dedicated local demonstration repository.
- No image-generated UI, replacement text, or composited feature panels.
- No network remote was configured for the example repository.
- Theme comparisons use the same selected commit and panel arrangement. Animated effects may differ between frames.

These assets illustrate the application; the release notes for a published build determine its available features and requirements.
